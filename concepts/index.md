# Concepts

* [Components](components.md) - Reusable, composable units that describe pieces of UI
* [Context](context.md) - Sharing values across the component tree without prop drilling
* [Effects](effects.md) - Synchronizing components with external systems via useEffect
* [Events](events.md) - Handling user interactions with synthetic events in React
* [Hooks](hooks.md) - Functions that let function components use state, context, and lifecycle features
* [JSX](jsx.md) - Syntax extension for describing UI structure in JavaScript
* [Props](props.md) - Read-only inputs passed from parent components to children
* [Rendering](rendering.md) - How React reconciles component trees and commits updates to the DOM
* [Router](router.md) - Client-side routing that maps URLs to components in single-page applications
* [State](state.md) - Mutable data owned by a component that triggers re-renders when updated
