# React Knowledge Pack

A self-contained OKF knowledge bundle for React fundamentals. Install this pack into any OKF-compatible client to browse concepts, follow prerequisites, and traverse the concept graph.

## Start here

New to React? Begin with [JSX](/concepts/jsx.md) — the syntax layer that lets you describe UI in JavaScript. From there, follow the **Core path** below in order. Each concept builds on the previous one.

If you already know components and props, jump to [State](/concepts/state.md) or [Hooks](/concepts/hooks.md) depending on whether you are migrating from class components or learning React fresh.

## Core path

The recommended learning order for React fundamentals:

1. [JSX](/concepts/jsx.md) — Syntax for describing UI in JavaScript
2. [Components](/concepts/components.md) — Reusable, composable UI units
3. [Props](/concepts/props.md) — Passing data into components
4. [State](/concepts/state.md) — Mutable data owned by a component
5. [Hooks](/concepts/hooks.md) — Functions that add state and lifecycle to function components
6. [Effects](/concepts/effects.md) — Synchronizing with external systems
7. [Context](/concepts/context.md) — Sharing data across the component tree

## Supporting concepts

Read these alongside or after the core path:

* [Rendering](/concepts/rendering.md) — How React turns components into DOM updates
* [Events](/concepts/events.md) — Handling user interactions
* [Router](/concepts/router.md) — Client-side navigation and URL-driven UI
